### Контент
- Собран весь английский сайт: 70 страниц, 685 новостей, 91 Best Practice, 114 ассоциаций NOA с контактами и числом олимпийцев с OLY, 10 членов Executive Committee с биографиями, 170 фото участников WOF.
- Тексты дословно. Свои слова только в служебных элементах (Search, Menu, Close, Home, All, List, Map, No results, Skip to content).
- Старые адреса работают: страницы-дубли и адреса с `?tab=`, `?year=` ведут на новые адреса.

### Новое по сравнению со старым сайтом
- Главная как лендинг: главная новость → цифры из About → Olympians → NOAs → News → OLY House → Best Practices.
- NOA Directory: на старом сайте в браузере пусто (данные подгружались скриптом). Теперь видны все 114 ассоциаций: поиск, буквы, карта/список, карточки с контактами.
- Grants: суммы, четыре шага с датами, критерии. Health: цифры исследования инфографикой. About: миссия, видение, цели, ценности с иконками. History: таймлайн. Leadership: фото и биографии в окне.
- Поиск по всем 932 страницам (иконка в шапке или клавиша «/»). Индекс лежит на самом сайте, запросы никуда не уходят.
- У всех новостей есть дата. Новости и Best Practices фильтруются по годам.
- Таблицы на телефоне превращаются в карточки. Видео грузится только по клику, с youtube-nocookie.com.

## Проверки (всё зелёное)
- Полнота: из 14 798 текстовых блоков старого сайта на новом найдены все, кроме одного. Это подпись вкладки «e-WOF», которую на оригинале разбивает тег; сама вкладка на месте. Скрипт: `node scripts/check.mjs`.
- Внутренние ссылки: проверено 78 822 ссылки. Битых 11, и все они ведут на страницы, которых нет и на оригинале (там тоже «Page not found»). На новом сайте по ним открывается своя страница 404. Скрипт: `node scripts/links.mjs`.
- Smoke-тест: 100 страниц × 390 / 834 / 1440, локально и на опубликованном сайте. Ноль проблем: нет боковой прокрутки, ошибок консоли и битых картинок, на каждой странице один h1. Скрипт: `node scripts/smoke.mjs <url>`.
- Вручную в браузере: поиск, мобильное меню, фильтры каталога, карта, вкладки Olympians for Life.

## Что не сделано и требует решения
1. **Французская и испанская версии.** На olympians.org они есть, здесь только английская. По правилу «сначала спросить, какие языки нужны» я их не делал. Архитектура готова, нужно ваше решение.
2. **Формы** (Register for OLY, Olympian.org Email, Contact Us, Best Practice) на этой копии данные не собирают. Кнопка отправки ведёт на ту же форму на olympians.org.
3. **Шрифт.** Официальный Verlag (Hoefler&Co) лицензирован только для домена организации, поэтому на сайте и в Figma стоит Montserrat. В копии старого сайта в Figma — Jost: он ближе к Verlag по ширине.
4. **Переключатель языков на странице OLY** (10 языков текста про OLY) убран: этих версий страницы здесь нет.
5. **На самом olympians.org сломаны 5 файлов** (сервер вместо них отдаёт страницу ошибки): фото Rosa Rakotozafy, две картинки старых новостей (832, 841), «NOA start-up guide» (PDF) и устав WOA 2015 года (PDF). На новом сайте вместо фото стоит аккуратная заглушка. Нужны исходные файлы от WOA.
6. **Что стоит добавить, когда WOA даст текст** (своими словами не писал): блок «кто может получить OLY» на странице OLY, отдельная страница для каждой NOA, статус приёма заявок на гранты, теги тем у новостей, страница для СМИ. Подробно в `docs/01-audience-and-flows.md`, раздел 5.

## Как обновлять
- Контент: `node scripts/crawl.mjs && node scripts/crawl-missing.mjs && node scripts/fetch-assets.mjs && node scripts/extract.mjs`.
- Сборка: `npm run build`. Публикация: `git push` (Actions сам соберёт и выложит).
- Figma: `scripts/figma/export.mjs` → `upload_assets` → `scripts/figma/fix-text.js`. Номера узлов в `docs/figma-log.md`.

## Дополнение 14.11.2026, ночь: смахивание окон
- Мобильное меню закрывается смахиванием вправо, поиск и карточки руководства — вниз (только касание; кнопка «закрыть» и Esc как раньше). Код: `src/lib/swipe.ts`.
- Окно идёт за пальцем 1:1, закрывается на 40% пути или быстрым смахиванием (скорость сохраняется), иначе возвращается; закрывающееся окно можно поймать и вернуть. Затемнение фона бледнеет с расстоянием.
- Если содержимое окна прокручено вниз, тянуть вниз значит прокручивать, а не закрывать.
- Окна появляются по той же оси, по которой уходят. При «уменьшить движение» окна открываются и закрываются без анимации; ведение пальцем остаётся.
- Проверено касаниями (Playwright, CDP touch) на 390 и 834: короткое протягивание, длинное, быстрое, перехват на лету, повторное открытие, прокрученное окно; smoke EN/FR — 0 проблем.
