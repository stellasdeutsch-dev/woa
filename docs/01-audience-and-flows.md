# World Olympians Association — анализ ЦА и пути пользователей

Основа: сайт olympians.org (краул 14.11.2026, 904 страницы, 685 новостей, 91 Best Practice, 114 ассоциаций NOA) и сравнение с сайтами IOC, Athlete365, ANOC, EOC, USOPC, OLY Canada, Team GB, NZOC и Olympic Refuge Foundation ([benchmark](research/olympic-sites-benchmark.md)).

## 1. Группы пользователей и их задачи

| Группа | Главные задачи | Где это на новом сайте |
|---|---|---|
| **Олимпиец** (основная аудитория) | получить OLY; завести адрес olympian.org; найти свою ассоциацию NOA; SkillsBuild; узнать про исследование здоровья; читать новости | кнопка «Register for OLY» в шапке на каждой странице; меню Olympians; блок Olympians на главной; NOA Directory |
| **Сотрудник или волонтёр NOA** | NOA Guide и шаблоны; гранты (суммы, сроки, условия); прислать Best Practice; контакты WOA | меню NOAs; страница Grants с суммами, сроками и критериями; документы с иконкой в боковой колонке; форма Best Practice |
| **Те, кто хочет создать NOA** | понять, что такое NOA, как вступить в WOA | NOA Guide → Overview («What is an NOA?», «How do I get involved?»), NOA start-up guide, Contact Us |
| **СМИ** | новости, руководство, контакты | News с фильтром по годам; Leadership с биографиями; Contact Us |
| **Партнёры и олимпийская семья** | цифры охвата, устав, стратегия, руководство | About: 100,000+ олимпийцев, 108 NOA, Strategic Plan, WOA Constitution; Leadership |
| **Болельщики** | истории, OLY House | главная (главная новость), Olympians for Life, OLY House |

## 2. Что было не так на старом сайте

- NOA Directory в браузере выглядел пустым: карта без данных, список подгружался скриптом.
- Главная — только плитки новостей; о том, кто такие WOA и что даёт OLY, на главной ни слова.
- Дата есть только у первой новости, у остальных нет.
- Нет поиска по 900 страницам.
- Меню капсом, выпадающие подменю без иконок; на мобильных отдельное меню-гамбургер с теми же пунктами.
- Grants: суммы, сроки и критерии — сплошной текст и таблица.
- Health: ключевые цифры исследования спрятаны в списке.
- Leadership: биографии переключались скриптом, без фото в списке.

## 3. Пути пользователей (сверены с навигацией нового сайта)

**Олимпиец получает OLY.** Любая страница → кнопка «Register for OLY» в шапке → страница OLY: две карточки «что даёт OLY», фото, обращение президента, видео → форма «Register for OLY» с кодексом поведения в раскрывающемся блоке → отправка на форму olympians.org.

**Олимпиец заводит адрес olympian.org.** Главная → блок Olympians → «Olympian.org Email» → описание, справка в боковой колонке (Signup, Login, инструкции для Android/iOS/Windows, FAQ) → форма регистрации.

**Олимпиец ищет свою ассоциацию.** Меню NOAs → NOA Directory → поиск по стране или названию / буква / карта → карточка: флаг, название, число олимпийцев с OLY → «Contact Details»: адрес, почта, сайт, телефон, президент.

**NOA подаёт на грант.** Меню NOAs → Grants → суммы ($1,000USD / до $5,000USD) → три вида грантов → Important Dates шагами → Eligibility и критерии → «Ideas can be suggested by any Olympian but your application must be submitted through your NOA» → NOA Directory.

**NOA берёт шаблоны.** Меню NOAs → NOA Guide → вкладки (Member Engagement, Branding & Marketing, …) → документы с иконкой документа в боковой колонке → скачивание.

**Будущая NOA.** NOA Directory → своей страны нет → NOA Guide → Overview → «How do I get involved?» → NOA start-up guide → Contact Us.

**Журналист.** Главная → News → фильтр по году → статья → «поделиться» (X, Facebook, LinkedIn, ссылка) → Leadership → Contact Us.

**Болельщик.** Главная → главная новость → статья → три похожих новости → OLY House.

## 4. Решения в редизайне

- Структура и названия разделов как на olympians.org (WOA, Olympians, NOAs, News, OLY House, Best Practices, SkillsBuild), в том же порядке. В подменю у каждого пункта своя иконка.
- Тексты дословно. Своих слов нет, кроме служебных: Search, Menu, Close, Home, All, List, Map, No results, Skip to content.
- Главная: главная новость → кто мы (цифры из About) → Olympians → NOAs → News → OLY House → Best Practices.
- Важные цифры, суммы и сроки выделяются везде одинаково (класс `.fact`).
- Поиск по всему сайту (Pagefind, индекс строится при сборке, ничего не уходит во внешние сервисы). Открывается иконкой в шапке или клавишей «/».
- Видео YouTube грузятся только по клику, с youtube-nocookie.com; превью лежат на самом сайте.
- Формы на этой копии не собирают данные: кнопка отправки ведёт на ту же форму на olympians.org.

## 5. Что стоит добавить, когда WOA даст текст (своими словами не писали)

- Блок «Кто может получить OLY» (eligibility) и «что будет после отправки» на странице OLY. Такой блок есть у USOPC.
- Отдельная страница для каждой NOA (`/noas/kenya/`), как у EOC.
- Статус грантов («открыт / закрыт до …») баннером, как у OLY Canada.
- Теги тем у новостей (Health, Grants, OLY, Events).
- Страница для СМИ: факты, руководство, контакт пресс-службы.
- Французская и испанская версии: на olympians.org они есть. Здесь пока только английская.
